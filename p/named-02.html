Why “0” may not mean “zero detected.”

A laboratory system can store a numeric value while a report-facing result communicates a different semantic state. If downstream software keeps only the number, meaning can be lost.

Source system

{
  "analyte": "Δ9-THC",
  "value": 0,
  "unit": "%",
  "lod": 0.005,
  "loq": 0.015,
  "reported_as": "ND"
}

Naive downstream interpretation:
Δ9-THC = 0%

WeedDAO interpretation

{
  "analyte_id": "delta9_thc",
  "measurement": {"value": 0,"unit": "%"},
  "result_state": "NOT_DETECTED",
  "limits": {"lod": 0.005,"loq": 0.015},
  "reported_as": "ND"
}

Preserved meaning:
numeric value, detection state, limits, and report-facing label remain distinct.

What the pilot checks

  • analyte identifiers and aliases
  • measurement units and conversions
  • ND / below-LOQ / not-tested / omitted semantics
  • LOD, LOQ, action limits, and other thresholds
  • sample, batch, and regulatory identifiers
